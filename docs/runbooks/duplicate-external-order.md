# Дубль внешнего заказа

Владелец: руководитель снабжения · Исполнитель: `procurement`

**Признаки:** два документа во внешней системе с одним externalCode / одним номером заказа PWA.

**Почему маловероятно:** ключ идемпотентности отправки, уникальный `dedupe_key` команды, сверка по externalCode перед каждым повтором (AT-05, тест).

**Ограничение ущерба:** остановить сборку второго документа во внешней системе.

**Восстановление:** отменить лишний документ во внешней системе; в PWA проверить `integration_mapping` заказа (одна связь); если связь указывает на отменённый — исправить администратором с записью в аудит.

**Сверка:** количество внешних документов за день = количество переданных заказов.

**Коммуникация:** складу — какой документ отменён; партнёру — только если затронуты сроки.
