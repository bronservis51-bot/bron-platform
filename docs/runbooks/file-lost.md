# Потеря файла

Владелец: владелец процесса, к которому относится файл · Исполнитель: администратор

**Признаки:** открытие файла даёт ошибку «Object not found»; метаданные `file_asset` есть, объекта в bucket нет.

**Ограничение ущерба:** доступ к остальным файлам не затрагивается; сама сущность (задача, обращение, оплата) и её история сохраняются.

**Восстановление:** найти файл в последней резервной копии `backups/<время>/files/<путь>` и загрузить по тому же пути (`npm run db:restore` загружает файлы, либо вручную через Storage с секретным ключом). Если копии нет — запросить файл у автора; связь с объектом и запись в истории сохраняются.

**Сверка:** выборка `file_asset` со статусом `ready` против списка объектов bucket — расхождений нет.

**Коммуникация:** автору файла — что требуется повторная загрузка.
