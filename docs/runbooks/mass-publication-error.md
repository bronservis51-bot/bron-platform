# Ошибочная массовая публикация

Владелец: владелец базы знаний · Исполнитель: `kb_editor` с kb.publish

**Признаки:** опубликована ошибочная редакция обязательного материала; аудитория получила назначения ознакомления.

**Ограничение ущерба:** опубликованные редакции неизменны — исправление публикуется новой редакцией; при грубой ошибке — «В архив» (статья исчезает из поиска, история и ознакомления сохраняются).

**Восстановление:** восстановить предыдущий текст: «Редактировать» (черновик создаётся из актуальной редакции; предыдущий текст — в истории редакций) → согласование → публикация с отметкой «Требуется повторное ознакомление», если ошибочная редакция содержала неверный порядок работы.

**Сверка:** актуальная редакция = исправленная; ознакомления с ошибочной редакцией видны в истории (для разбора, если по ней уже работали).

**Коммуникация:** аудитории — что изменилось и что делать, если уже работали по ошибочной версии.
