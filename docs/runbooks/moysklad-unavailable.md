# «МойСклад» недоступен

Владелец: руководитель снабжения · Исполнитель: роль `procurement` (integration.operate)

**Признаки:** заказы со статусом «склад недоступен — повтор автоматически»; «Настройки → Интеграции» — подключение «сбои», в outbox записи `failed`; при исчерпании попыток — критическая задача «Обмен остановлен».

**Ограничение ущерба:** заказы не теряются — сохранены в PWA, повторы идут с увеличивающейся задержкой. Партнёрам статус показывается честно («ожидает передачи на склад»), ложного «принят складом» нет.

**Восстановление:** после восстановления склада — «Обработать очередь сейчас»; для `dead` — «Повторить» (адаптер сначала сверит, не создан ли документ). Срочные отгрузки — вручную во внешней системе, затем «Решено вручную» с номером документа.

**Сверка:** заказы с `transfer_status ≠ sent` за период = 0; номера внешних документов совпадают с заказами.

**Коммуникация:** уведомление партнёрам с задержанными заказами: причина, ожидаемое время, что ничего делать не нужно.
