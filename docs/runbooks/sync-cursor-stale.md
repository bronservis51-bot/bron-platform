# Курсор синхронизации устарел

Владелец: владелец интеграции · Исполнитель: `integration.operate`

Применимо после подключения реальных адаптеров (Drive `changes.pageToken`, вебхуки «МойСклад»). В прототипе курсоров нет.

**Признаки:** ошибка «invalid page token»/отставание синхронизации выше порога в «Настройки → Интеграции».

**Ограничение ущерба:** опубликованные данные PWA не меняются от внешних событий без проверки (кандидатные редакции, проекции остатков с временем обновления).

**Восстановление:** получить новый стартовый курсор; выполнить полную сверку (перечитать состояния объектов через API) — сверка обязательна, так как события за период разрыва потеряны; затем продолжить инкрементально.

**Сверка:** сравнить счётчики объектов и контрольные суммы исходников до/после.

**Коммуникация:** редакторам — список кандидатных редакций, появившихся после сверки.
