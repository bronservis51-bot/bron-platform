# Неправильное распределение платежа

Владелец: финансовый руководитель · Исполнитель: роль `finance` (payment.allocate)

**Признаки:** оплата распределена не на тот период/договор; партнёр видит неверное сальдо.

**Ограничение ущерба:** распределения не удаляются, только сторнируются; сумма распределений никогда не превышает платёж (ограничение в БД, AT-10).

**Восстановление:** карточка начисления → «Сторно» у ошибочного распределения с причиной → «Распределить оплату» на верное начисление. Если ошибочен сам платёж — «Возврат платежа» (все распределения сторнируются, долг восстанавливается).

**Сверка:** сальдо партнёра = сумма начислений + корректировки − подтверждённые распределения; нераспределённый остаток платежа соответствует выписке.

**Коммуникация:** партнёру — исправление с указанием периода и суммы (видно в истории начисления).
