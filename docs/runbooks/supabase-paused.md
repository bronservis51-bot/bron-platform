# Демо-проект Supabase приостановлен

Владелец: владелец продукта · Исполнитель: администратор аккаунта Supabase

**Признаки:** экран входа отвечает «Сервер недоступен»; в панели Supabase проект в статусе Paused (Free-проекты останавливаются после 7 дней без активности [S9]).

**Ограничение ущерба:** данные при паузе сохраняются; новые операции невозможны — сообщить участникам демо.

**Восстановление:** Supabase Dashboard → проект → Restore/Resume project (несколько минут). Проверить «Настройки → Интеграции»: запуски обработки возобновились.

**Профилактика:** перед демонстрацией открыть стенд за день; на время пилота — еженедельная активность или решение о постоянном хостинге (COST-14). Платный тариф автоматически не подключать.

**Коммуникация:** сообщение участникам: «Стенд был приостановлен провайдером из-за неактивности, данные сохранены, работа восстановлена в HH:MM».
