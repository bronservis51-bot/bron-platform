# Google Drive отозвал доступ

Владелец: владелец базы знаний (kb_editor/руководитель) · Исполнитель: `kb_editor`

**Признаки:** статьи режима «исходник в Drive» в статусе «приостановлена»; задача «Восстановить доступ к исходнику статьи»; экспорт копий — «копия не сохранена».

**Ограничение ущерба:** приостановленная статья скрыта из поиска и выдачи (KB-12) — никто не увидит материал без проверенного права; опубликованные native-статьи продолжают работать; история и ознакомления сохраняются.

**Восстановление:** восстановить права сервисного доступа в Drive → «Восстановить доступ»; для экспорта — «Повторить» в outbox.

**Сверка:** статьи `suspended` = 0; `export_status = failed` = 0; последняя копия свежее порога.

**Коммуникация:** авторам и читателям приостановленных статей — что материал временно недоступен и где взять замену.
