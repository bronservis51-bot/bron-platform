# Фоновая обработка остановлена

Владелец: владелец продукта · Исполнитель: администратор

**Признаки:** «Настройки → Интеграции → Запуски обработки» — нет запусков «По расписанию» дольше 15 минут; растёт очередь outbox `pending`; не приходят напоминания.

**Ограничение ущерба:** операции пользователей не теряются — команды и события лежат в outbox/inbox; в прототипе оператор может нажать «Обработать очередь сейчас».

**Восстановление:** Supabase → Integrations → Cron: проверить задание `bron-jobs` (`*/5 * * * *`, `select app_private.run_jobs('cron')`) и журнал запусков; при отсутствии — пересоздать (миграция 0010). Затем ручной запуск для «догона».

**Сверка:** outbox `pending` старше 10 минут = 0; задачи-напоминания периода созданы (дедупликация не допустит дублей при догоне).

**Коммуникация:** не требуется, если задержка меньше часа; иначе — пользователям с задержанными заказами.
