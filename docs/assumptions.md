# Факты, допущения и вопросы

Статусы: **факт** — подтверждено источником; **допущение** — рабочая гипотеза, по которой ведётся разработка, с отметкой, что её нужно подтвердить; **вопрос** — нужен ответ владельца; **решено** — ответ получен.

Обезличено: в репозитории нет имён сотрудников и условий конкретных договоров. Исходные сведения — в исходной спецификации у владельца.
