# Уточнённая спецификация платформы «Бронь Сервис»

Основание: «Спецификация корпоративной платформы Бронь Сервис», версия 1.2 от 12.10.2026 (далее — «исходная спецификация»).
Редакция этого документа: 1.3-draft · 12.10.2026 · статус: на согласовании у владельца.

Документ не заменяет исходную спецификацию, а уточняет её: фиксирует постоянные ID, приоритет, признак включения в бесплатный прототип и проверяемые критерии приёмки. Где исходный текст оставлял неоднозначность, ниже записано принятое толкование и ссылка на допущение (`A-xx` в [assumptions.md](assumptions.md)) или ADR.

Связанные документы: [процессы](processes.md) · [доменная модель](domain-model.md) · [архитектура](architecture.md) · [дизайн-система](design-system.md) · [интеграции](integrations.md) · [план поставки](delivery-plan.md) · [проверки](test-plan.md).

## 0 Понимание целей

1. **Для сотрудника и партнёра** — один ответ на вопрос «что мне сделать сегодня, до какого срока, для какой точки и что мешает».
2. **Для руководителя** — список исключений, требующих вмешательства, где каждое число раскрывается до объектов и объясняет расчёт.
3. **Для компании** — работа принадлежит очередям ролей, а не памяти людей: при смене сотрудника задачи, обещания и история сохраняются.
4. **Для франшизы** — масштабирование числа точек без пропорционального роста ручной работы: шаблонные открытия, маршрутизируемая поддержка, сквозной заказ, прозрачные роялти.
5. **Ограничение первого шага** — работающий прототип на GitHub Pages + Supabase Free за 0 ₽ (раздел 25 исходной спецификации имеет приоритет для прототипа).

Приоритеты требований: **P0** — условие любого production; **P1** — первый франшизный контур; **P2** — развитие; **P3** — оптимизация. Колонка «Прототип»: **да** — реально работает в бесплатном прототипе; **demo** — работает через явно помеченный demo-адаптер; **частично** — сокращённый объём, ограничение указано; **нет** — следующий этап.
