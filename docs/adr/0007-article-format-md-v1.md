# ADR-0007 Формат статей базы знаний

Статус: принято

## Контекст
KB-03: формат хранения со схемой и миграциями; HTML очищается. KB-10/19: экспорт в открытый формат и независимость от PWA.

## Решение
Тело редакции — CommonMark с таблицами (GFM), **сырой HTML запрещён** (`markdown-it` с `html: false`), поле `body_format = 'md-v1'`. Рендер: markdown-it → DOMPurify. Ссылки на сущности — `[текст](app:task/<id>)`, изображения — `![alt](file:<file_id> "подпись")`. Для поиска хранится `body_text` (текст без разметки) и `tsvector`.

## Последствия
- Экспорт — тот же Markdown + JSON-метаданные: читается без PWA.
- Переход на блочный редактор потребует формата `blocks-v1` и миграции; поле `body_format` это поддерживает.
