# ADR-0008 Маршрутизация и обновление PWA на GitHub Pages

Статус: принято

## Контекст
COST-16: сборка в подкаталоге `/<repo>/`, без серверных rewrite; PWA-06: обновление не должно терять черновики и не должно активировать новый service worker посреди отправки.

## Решение
- Hash-маршруты (`/#/orders/…`): прямая ссылка и перезагрузка вложенного экрана работают без rewrite.
- `base`, `manifest.start_url` и `scope` берутся из переменной `VITE_BASE_PATH`.
- Service worker в режиме `prompt`: новая версия ждёт; пользователь видит «Доступно обновление» и применяет его, когда нет незавершённой отправки (счётчик активных команд в адаптере backend).
- Кешируется только оболочка (JS, CSS, иконки, offline-страница). Ответы API и файлы не кешируются service worker'ом (PWA-05).
- Локальная схема IndexedDB версионируется; обновление выполняет миграцию, а не очистку.

## Последствия
URL содержат `#`; при переходе на хостинг с rewrite можно включить history-маршруты без изменения экранов.
