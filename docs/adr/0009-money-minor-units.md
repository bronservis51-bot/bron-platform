# ADR-0009 Деньги и округление

Статус: принято

## Решение
- Суммы — `bigint` в минорных единицах валюты (`currency.minor_unit`); всегда вместе с кодом валюты. В TypeScript — `bigint`-безопасное представление строкой из БД и форматирование через `Intl.NumberFormat` без арифметики на float.
- Ставка — целые базисные пункты (`rate_bp`, 1 bp = 0,01%).
- Начисление = round(база × rate_bp / 10 000) по правилу политики (`half_up` по умолчанию в тестовых договорах), вычисляется в `numeric`, результат — `bigint`. Округление применяется к итогу по договору; разбивка по точкам — справочная.
- Суммы разных валют не складываются; показатели выводятся по каждой валюте отдельно. Пересчёт — только по отдельному правилу с источником курса (не реализуется в прототипе).
